## 1. Чат (главный экран)

```
┌────────────────────────────────────────┐
│ ● opencode                            │
├────────────────────────────────────────┤
│ Ты: напиши парсер SSE                 │
│                                       │
│ opencode:                             │
│  ┌─ bash ───── running ─┐            │
│  └───────────────────────┘            │
│ Готово. Вот парсер:                  │
│ ```rust                               │
│ // ...                                │
│ ```                                   │
│                                       │
├────────────────────────────────────────┤
│ [🎤] [────── текст ───────] [▶]      │
└────────────────────────────────────────┘
```

- **●** — индикатор: зелёная = подключено, серая = нет
- **[🎤]** — PTT кнопка (позиция: лево/право, настройка)
- **НЕТ кнопок в шапке!** Палец не должен тянуться вверх

### Жесты на экране чата
```
┌────────────────────────────────────────┐
│                                        │
│                                        │
│    ↙ свайп вправо →                    │
│    открывает настройки                │
│    ТЕКУЩЕЙ СЕССИИ (локальные)         │
│                                        │
├────────────────────────────────────────┤
```
- Свайп **вправо** → настройки локальные (текущего чата)
- Настройки выезжают СЛЕВА (вытягиваешь справа)

## 4в. Параметры ввода и озвучки (в настройках)

```
СПОСОБ ВВОДА (3 опции)
  ○ только текст (инпут, без PTT)
  ● текст + PTT (оба способа)   ← по умолчанию
  ○ только диктовка (PTT, без инпута)

ОЗВУЧКА ОТВЕТОВ (3 опции)
  ○ авто-озвучка + кнопка 🔉 повтора
  ● только кнопка 🔉 на ответе    ← по умолчанию
  ○ без озвучки (нет кнопки, TTS выкл)
```

## 4г. Зависимые настройки (блокировка)

Некоторые настройки доступны только при условии другой настройки.
Блокированная настройка: **серая, неактивная** (не скрывать!)

```
┌────────────────────────────────────────┐
│ СПОСОБ ВВОДА                          │
│ ○ только текст   ← PTT отключён      │
│                                       │
│ PTT ПОЗИЦИЯ                           │
│ ○ лево ● право  ▓ блокировано       │
│   (нет PTT в способе ввода)          │
│                                       │
│ [ ] Сразу отправлять  ▓ заблокировано│
│   (требует включённого PTT)          │
└────────────────────────────────────────┘
```

### Правила
- **Позиция PTT** — требует способ ввода с PTT:
  `текст+PTT` или `только диктовка`
- **Сразу отправлять** — требует включённого PTT
- **Озвучка ответов (все 3 опции)** — требует скачанной
  TTS-модели Piper. Модели нет → блок.
- **Распознавание (STT-опции)** — требует скачанной
  STT-модели whisper.cpp
- Заблокированный пункт показывает «почему»:
  «Требуется модель: Скачать»

## 5. Permission (карточка поверх чата)

```
┌────────────────────────────────────────┐
│ ⚠ opencode просит:                    │
│                                       │
│ bash: grep -r "TODO" src/            │
│                                       │
│ [ Вариант 1 от сервера ]             │
│ [ Вариант 2 от сервера ]             │
│ [ Вариант 3 от сервера ]             │
└────────────────────────────────────────┘
```

**Важно:** рендерим ровно то, что сервер прислал.
Не придумываем варианты. Если 2 кнопки — 2.
Если 3 — 3. Если 4 — 4.

## 6. PTT → STT → opencode

```
 Зажал 🎤 → запись → отпустил
   ↓
 STT (whisper, локально)
   ↓
 ┌─ тумблер "Сразу отправлять"? ─┐
 │  ДА: текст → prompt_async     │
 │  НЕТ: текст → поле ввода      │
 └────────────────────────────────┘
   ↓
 opencode: SSE → ответ в чат
```

Агент работает → экран заблокирован →
при завершении/permission → звук "дзинь"
+ уведомление в системном шаре Sailfish.

## 8. Язык интерфейса (i18n)

- **Текущий:** только английский (en)
- **Формат:** `i18n/{lang}.json`

```json
// i18n/en.json (эталон — все ключи обязательны)
{
  "sessions.title": "Sessions",
  "settings.title": "Settings",
  "permission.title": "opencode asks",
  "ptt.recording": "Recording...",
  "ptt.processing": "Processing..."
}
```

**Правило: новый язык активируется ТОЛЬКО если файл
полностью завершён — присутствуют ВСЕ обязательные поля.**

```
i18n/ru.json
  ✅ все ключи = ru интерфейс
  ❌ не хватает 2 полей = язык НЕ показывается в списке
     (нет смеси языков на экране)
```

- Добавление перевода: скопировать `en.json`, заполнить значения,
  когда всё заполнено → язык появится в настройках

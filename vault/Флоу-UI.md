## 1. Чат (главный экран)

```
┌────────────────────────────────────────┐
│ [≡] opencode                   [⚙]   │
├────────────────────────────────────────┤
│ Ты: напиши парсер SSE                 │
│                                       │
│ opencode:                             │
│  ┌─ bash ───── running ─┐            │
│  └───────────────────────┘            │
│ Готово. Вот парсер:                  │
│ ```rust                               │
│ // ...                                │
│ ```                                   │
│                                       │
├────────────────────────────────────────┤
│ [🎤] [────── текст ───────] [▶]      │
└────────────────────────────────────────┘
```

- **[≡]** — слева, открывает **список сессий**
- **[⚙]** — справа, открывает **настройки** (текущей сессии)
- **●** — индикатор: зелёная = подключено, серая = нет
- **[🎤]** — PTT кнопка (позиция: лево/право, настройка)

## 2. Список сессий (открывается слева)

```
┌────────────────────────────────────────┐
│ [≡] Сессии                       [≡]  │
├────────────────────────────────────────┤
│ ●  Парсер SSE (текущая)              │
│ ○  Refactor main.rs                   │
│ ○  Fix CSS баг                        │
│ ○  Новая фича: авторизация            │
│                                       │
├────────────────────────────────────────┤
│ PullDown:                             │
│  ○ Новая сессия                       │
│  ○ Настройки                          │
└────────────────────────────────────────┘
```

- PullDown меню допустимо **только здесь** (нет конфликтующего скролла)
- Клик по сессии → открывает чат этой сессии

## 4. Permission (карточка поверх чата)

```
┌────────────────────────────────────────┐
│ ⚠ opencode просит:                    │
│                                       │
│ bash: grep -r "TODO" src/            │
│                                       │
│ [ Вариант 1 от сервера ]             │
│ [ Вариант 2 от сервера ]             │
│ [ Вариант 3 от сервера ]             │
└────────────────────────────────────────┘
```

**Важно:** рендерим ровно то, что сервер прислал.
Не придумываем варианты. Если 2 кнопки — 2.
Если 3 — 3. Если 4 — 4.

---

## 5. PTT → STT → opencode

```
 Зажал 🎤 → запись → отпустил
   ↓
 STT (whisper, локально)
   ↓
 ┌─ тумблер "Сразу отправлять"? ─┐
 │  ДА: текст → prompt_async     │
 │  НЕТ: текст → поле ввода      │
 └────────────────────────────────┘
   ↓
 opencode: SSE → ответ в чат
```

---

## 6. Фоновый режим

Агент работает → экран заблокирован →
при завершении/permission → звук "дзинь"
+ уведомление в системном шаре Sailfish.

## 7. Язык интерфейса

- **Текущий:** только английский (en)
- **Будущее:** конфиг для переводов
- Формат: `i18n/{lang}.json`
- Пример `i18n/en.json`:
  ```json
  {
    "chat.title": "Chat",
    "settings.title": "Settings",
    "permission.allow": "Allow",
    "permission.deny": "Deny",
    "ptt.recording": "Recording...",
    "ptt.processing": "Processing..."
  }
  ```
- Добавление нового языка: создать `i18n/ru.json`,
  заполнить ключи → переключатель в настройках

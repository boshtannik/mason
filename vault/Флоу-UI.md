# Флоу-диаграммы: Sailfish-opencode UI

> Как будет выглядеть окно. Текстовые версии. Актуально на 2026-09-16.
> Решение: без гамбургера, без кнопки «меню» в шапке — нативные Sailfish-паттерны.

## Экран 1: Чат (главный)

```
┌─────────────────────────────────────────────────────────────┐
│ ● opencode   ──────────────────────────────── [ счётчик ]    │  ← шапка
│   ^ зелёная точка = сервер ок                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  Я: «напиши парсер SSE на Rust»                      │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  opencode:                                            │  │
│  │    ┌─ тул baш ──────────── ok ─────┐                 │  │
│  │    │ tool/bat/bash  [blinking]     │  ← статус тула   │  │
│  │    └────────────────────────────────┘                 │  │
│  │  Готово. Вот парсер:                                 │  │
│  │  ```rust                                              │  │
│  │  // ...код...                                          │  │
│  │  ```                                                  │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
│  (лента истории, скроллится)                                │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ [ 🎤 PTT ]  [──────────── поле ввода ────────────────] [▶]  │  ← нижняя панель
└─────────────────────────────────────────────────────────────┘
```

**Нижняя панель (всегда видна):**
- **🎤 PTT** — большая круглая кнопка слева. Зажал → горит красным, идёт запись ГОЛОСА (микрофон). Отпустил → STT распознаёт → текст попадает в поле ввода.
- **поле ввода** — туда же можно печатать/вставлять вручную. После отпускания PTT сюда попадает распознанный текст.
- **▶** — «отправить». Отправляет текст в opencode (prompt_async).

```
┌─────────────────────────────────────────────────────────────┐
│ ● opencode                                        [ настройки]│
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐      │
│                    │  ⚠️ opencode запрашивает:          │      │
│                    │                                    │      │
│                    │  «Редактировать файл:              │      │
│                    │    /home/user/foo.md»              │      │
│                    │                                    │      │
│                    │  [ ✓ Разрешить ] [ ✕ Запретить ]  │      │
│                    └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘      │

Пока карточка висит — opencode **ждёт** (нить busy). Каждый клик по
кнопке — `POST /session/{id}/permissions/{pid}` с `{ response, remember? }`.

## Главный флоу: PTT → STT → opencode → ответ

```
 ┌─────────┐     ┌──────────┐     ┌───────────┐     ┌─────────┐
 │ Зажал 🎤 │ ──▶ │ Запись ▲ │ ──▶ │ STT (wiсper│ ──▶ │ Текст в│
 │ (PTT)   │     │ (микрофон)│    │ :8081)    │     │ поле    │
 └─────────┘     └──────────┘     └───────────┘     └─────────┘
                                                                 
 ┌─────────┐     ┌──────────┐     ┌───────────┐     ┌─────────┐
 │ [▶] (руч.│ ──▶ │ opencode │ ──▶ │ SSE-поток │ ──▶ │ Ответ   │
 │ или авт.) │     │ prompt_  │     │ /global/  │     │ появля  │
 │          │     │ async    │     │ event     │     │ ется    │
 └─────────┘     └──────────┘     └───────────┘     └─────────┘
```

**PTT как один флоу:** PTT → распознанный текст → вопрос: *«Сразу
отправлять в opencode ИЛИ вставить в поле для проверки?»* → настраивается
тумблером в Настройках («Сразу отправлять распознанное»).

## Флоу Permission (внутри сессии)

```
opencode → app: event "permission.updated" (требует доступ)
app → пользователь: карточка ⚠️ «Редактировать файл X?»
пользователь → app: [Разрешить] / [Запретить]
app → opencode: POST /session/{ID}/permissions/{pid} {response}
opencode → app: SSE "permission.replied" → тул продолжает / останавливается
```

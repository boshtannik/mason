## 1. Чат (главный экран)

```
┌────────────────────────────────────────┐
│ ● opencode                    [ ⚙ ]    │
├────────────────────────────────────────┤
│ Ты: напиши парсер SSE                  │
│                                        │
│ opencode:                              │
│  ┌─ bash ────── running ─┐            │
│  └────────────────────────┘            │
│ Готово. Вот парсер:                   │
│ ```rust                                │
│ // ...                                 │
│ ```                                    │
│                                        │
├────────────────────────────────────────┤
│ [🎤] [──────── текст ──────────] [▶]  │
└────────────────────────────────────────┘
```

- **●** — зелёная = подключено, серая = нет
- **[ ⚙ ]** — настройки (PullDown или справа)
- **[🎤]** — PTT кнопка (позиция: слева/справа, настройка)

## 2. Permission (больше 2-х вариантов)

```
┌────────────────────────────────────────┐
│ ● opencode                            │
├────────────────────────────────────────┤
│ ⚠ opencode просит:                    │
│                                        │
│ bash: grep -r "TODO" src/             │
│                                        │
│ [ Разрешить ]                          │
│ [ Всегда разреш. ]                     │
│ [ Запретить ]                          │
│ [ Всегда запрет. ]                     │
└────────────────────────────────────────┘
```

Варианты ответа: allow / always allow / deny / always deny.
"Всегда" = remember=true (запоминает на сессию).

## 4. PTT → STT → opencode

```
 Зажал 🎤 → запись → отпустил
   ↓
 STT (whisper, локально)
   ↓
 ┌─ тумблер "Сразу отправлять"? ─┐
 │  ДА: текст → prompt_async     │
 │  НЕТ: текст → поле ввода      │
 └────────────────────────────────┘
   ↓
 opencode: SSE → ответ в чат
```

---

## 5. Permission флоу

```
opencode → app: permission.updated
app → звук "дзинь" (если настроено)
app → пользователь: 4 варианта
пользователь → app: ответ
app → opencode: POST /permissions/{pid}
```

---

## 6. Фоновый режим

Агент работает → экран заблокирован →
при завершении/permission → звук "дзинь"
+ уведомление в системном шаре Sailfish.

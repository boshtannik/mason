## Потоки данных

**Входящий (SSE):**
```
opencode server --SSE(200)--> sse.rs --> Event --> state/* (FSM) --> bridge --> QML
```

**Исходящий (действия):**
```
QML (кнопка/инпут) --> bridge --> api/* --> opencode server
```

**Permission (диалог):**
```
opencode --permission.updated--> state/permission → QML PermissionDial
Пользователь: Allow/Deny → api/permission.answer → server
```

**PTT (голос):**
```
QML PTTButton (зажал) → запись аудио (ALSA/Pulse) → файл .ogg
  → POST /audio/transcriptions (Groq, whisper-large-v3) → текст → инпут
Ответ: text из сессии → Edge TTS (HTTP-запрос) → .mp3/ogg → проигрывание
```

## Сборка (на ноутбуке, не на телефоне)

Вариант A (простой, qmetaobject-rs):
- tar Возможность: кросс-компиляция `aarch64-unknown-linux-gnu` с sysroot из SDK.
- Прибивание Сила: qmetaobject-rs умеет собираться под aarch64 Linux без полного SDK,
  если есть Qt dev headers для aarch64.

Вариант B (родной для Sailfish):
- Sailfish SDK (OS1), проект `sfos` → соберёт RPM `.rpm.harbourarmv7hl`... но у нас aarch64.
- Лучше: `target: aarch64`, SDK OS1 + `sb2 -t SailfishOS-5.1.0.11.aarch64`.

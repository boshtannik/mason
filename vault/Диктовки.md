# Диктовки: флоу и UX

> Все решения по интерфейсу, которые диктовал пользователь.
> Добавлять сюда каждое решение.

---

## 2026-09-16

### Старт
- При открытии → сразу окно чата, не список сессий
- Список сессий доступен через свайп/переход
- Сервер opencode запускается сам (часть RPM), пользователь не знает о нём
- Показывать индикатор подключения (● зелёная/серая)

### Чат
- Лента сообщений как в мессенджере
- Стриминг ответа в реальном времени
- Индикация активных тулов (tool status)

### PTT (Push to Talk)
- Кнопка для голосового ввода
- Один флоу: зажал → запись → отпустил → STT
- Тумблер в настройках: сразу отправлять распознанное ИЛИ вставлять в поле
- Позиция кнопки: лево/право (настройка для левшей/правшей)

### Permission
- Больше 2-х вариантов: Разрешить / Всегда разрешить / Запретить / Всегда запретить
- Формат: понятное описание что именно просит агент
- Пока не отвечен — сессия ждёт

### STT/TTS
- Только локально (без облака)
- Как в Speech Note (mkiol/dsnote): скачивание моделей через UI
- whisper.cpp для STT, Piper для TTS
- Модели хранятся локально, выбираются в настройках

### Уведомления
- Звук "дзинь" по завершении работы агента
- Звук при запросе permission
- Настройки включать/выключать

### opencode serve
- Идёт вместе в RPM-пакете
- Пользователь ставит → открывает → работает
- Не нужно отдельно запускать/настраивать

### SSH к телефону
- Не нужен для сборки — собираем на ноуте через кросскомпиляцию
- Только для установки готового RPM

### Permission (уточнение)
- Не придумывать варианты в GUI — рендерить ровно то, что сервер прислал
- Если сервер вернул 2 варианта — 2 кнопки, если 3 — 3, если 4 — 4
- Описания тоже от сервера, не нашего製

### Меню (уточнение — БЕЗ кнопок!)
- Кнопки в шапке ОТМЕНЕНЫ. Палец не должен тянуться вверх экрана.
- Навигация только свайпами:
  - Экран чата: свайп **вправо** → настройки ТЕКУЩЕЙ сессии (локальные)
  - Экран списка сессий: свайп **влево** → настройки ГЛОБАЛЬНЫЕ
- PullDown меню допустимо ТОЛЬКО на экране списка сессий (нет конфликтующего скролла)
- На экране чата PullDown НЕ используется (конфликтует со скроллом ленты)
- Это продумано для удобства использования одной рукой:
  жесты снизу/из середины, не из шапки

### Язык интерфейса (уточнение)
- Текущий: только английский (en)
- Будущее: конфиг для переводов (i18n/{lang}.json)
- **ЖЁСТКОЕ ПРАВИЛО:** новый язык появляется в списке ТОЛЬКО когда
  файл перевода ПОЛНОСТЬЮ заполнен (все обязательные поля на месте).
  Не полностью переведённый язык НЕ показывается.
  Это исключает смесь языков на одном экране.
